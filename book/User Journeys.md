### مسیرها

در اینجا سناریوهای کامل را به تفکیک هر بازیگر و مطابق وضعیت فعلی اپلیکیشن «نون گرد» مرور می‌کنیم. هستهٔ محصول **کتاب‌های پرفروش نیویورک تایمز با ترجمهٔ هوش مصنوعی** است: کتاب‌های ارائه‌شده از لیست پرفروش‌های نیویورک تایمز انتخاب می‌شوند؛ ترجمهٔ هر کتاب به‌صورت مستقل و **خارج از محدودهٔ این پروژه** انجام می‌شود و محصول نهایی (نسخهٔ فارسی) توسط ادمین به برنامه اضافه می‌شود. کاربران با ثبت درخواست ترجمه، اولویت خود را به ادمین نشان می‌دهند، به کیفیت ترجمهٔ کتاب‌های ترجمه‌شده رأی می‌دهند و صفحهٔ اول نیز بازدیدکننده را با همین ارزش پیشنهادی آشنا می‌کند. تمام صفحات، پیام‌ها و اعلان‌ها به فارسی هستند و تاریخ‌های نمایش‌داده‌شده به تقویم شمسی با ارقام فارسی است.

#### الف) مسیرهای بینندهٔ ناشناس (Anonymous)
1. **آشنایی با برنامه (صفحهٔ اول)**:
   `صفحهٔ اول` -> مطالعهٔ بخش معرفی: «ترجمهٔ هوش مصنوعی — دسترسی سریع به نسخهٔ فارسی کتاب‌های خارجی» و «کتاب‌های پرفروش نیویورک تایمز» -> کلیک روی دکمه/لینک `مشاهدهٔ کتاب‌ها` -> `لیست کتاب‌ها`.
2. **کشف و مرور کتاب‌ها**:
   `صفحهٔ اول` -> `لیست کتاب‌ها` -> (جستجو بر اساس عنوان / فیلتر دسته‌بندی / صفحه‌بندی) -> `مشخصات کتاب`.
3. **اشتراک‌گذاری یا کپی لینک کتاب**:
   `مشخصات کتاب` -> کلیک روی `کپی لینک` (یا `اشتراک‌گذاری` در مرورگرهای سازگار) -> دریافت لینک کتاب.
4. **افزودن به کتابخانه (هدایت هوشمند ناشناس)**:
   `مشخصات کتاب` -> کلیک روی `افزودن به کتابخانه` -> **هدایت به صفحهٔ ثبت‌نام/ورود** (`/login?returnUrl=...`) -> ورود/ثبت‌نام موفق -> **بازگشت خودکار به همان کتاب** -> نمایش پیام «به کتابخانه اضافه شد».
5. **دانلود کتاب (هدایت هوشمند ناشناس)**:
   `مشخصات کتاب` -> کلیک روی `دانلود کتاب` -> **هدایت به صفحهٔ ورود** -> ورود/ثبت‌نام موفق -> **دانلود خودکار فایل کتاب**.
6. **ثبت‌نام با ایمیل و رمز عبور**:
   `صفحهٔ ثبت‌نام` -> پر کردن فرم (نام، نام خانوادگی، ایمیل، رمز) -> ثبت‌نام موفق -> ورود خودکار + پیام خوش‌آمد.
7. **ثبت‌نام/ورود با گوگل**:
   `صفحهٔ ورود/ثبت‌نام` -> کلیک روی `ورود با گوگل` -> تأیید در گوگل -> بازگشت و ورود خودکار (اگر ایمیل قبلاً ثبت نشده باشد، حساب به‌صورت خودکار ساخته می‌شود).
8. **خطا در احراز هویت**:
   `صفحهٔ ثبت‌نام/ورود` -> اطلاعات نادرست، رمز کوتاه یا ایمیل تکراری -> **ماندن در همان صفحه** و نمایش خطای فارسی (خطاهای اعتبارسنجی کنار فیلدها، خطاهای عملیاتی به‌صورت اعلان).
9. **فراموشی رمز عبور و بازیابی**:
   `صفحهٔ ورود` -> کلیک روی «فراموشی رمز عبور» -> وارد کردن ایمیل -> دریافت لینک بازیابی از طریق ایمیل -> `صفحهٔ بازیابی رمز` -> رمز جدید -> ورود با رمز جدید (همهٔ جلسات قبلی باطل می‌شود).
10. **مرور کتاب‌های پرفروش نیویورک تایمز**:
    `صفحهٔ اول` -> بخش «پرفروش‌های نیویورک تایمز» (یا نشان روی کارت کتاب‌ها) -> `لیست کتاب‌ها` -> `مشخصات کتاب`.
11. **مشاهدهٔ وضعیت ترجمه و دانلود نسخهٔ فارسی**:
    `مشخصات کتاب` -> مشاهدهٔ وضعیت ترجمه («ترجمه‌شده» / «ترجمه‌نشده») -> (اگر ترجمه‌شده) کلیک روی `دانلود کتاب` -> در صورت ناشناس بودن، **هدایت به ورود** -> دانلود نسخهٔ فارسی.
12. **مشاهدهٔ مشخصات پرفروش بودن (NYT)**:
    `مشخصات کتاب` -> مشاهدهٔ مدت حضور در لیست پرفروش‌های نیویورک تایمز (مثلاً «۱۵ هفته در لیست») و وضعیت فعلی («هم‌اکنون در لیست است» / «قبلاً در لیست بوده»).

#### ب) مسیرهای کاربر ثبت‌نام‌شده (Registered User)
13. **مشاهدهٔ کتابخانهٔ شخصی**:
    `صفحهٔ اول` (یا هر صفحه) -> کلیک روی «کتابخانه» در منو -> `لیست کتاب‌های کاربر`.
14. **افزودن کتاب جدید به کتابخانه**:
    `لیست کتاب‌ها` -> `مشخصات کتاب` -> کلیک `افزودن به کتابخانه` -> **ماندن در همان صفحه** با اعلان موفقیت (دکمه به «در کتابخانهٔ شماست» تغییر می‌کند).
15. **حذف کتاب از کتابخانه**:
    `لیست کتاب‌های کاربر` -> کلیک روی ✕ روی کارت (یا `مشخصات کتاب` -> دکمهٔ `حذف از کتابخانه`) -> تأیید در دیالوگ -> حذف و نمایش اعلان.
16. **نشان‌گذاری وضعیت کتاب در کتابخانه (خوانده‌شده / در فهرست علاقه‌مندی‌ها)**:
    `لیست کتاب‌های کاربر` (یا `مشخصات کتاب`) -> انتخاب وضعیت «خوانده‌شده» یا «در فهرست علاقه‌مندی‌ها» (یا حذف وضعیت) -> ذخیره + اعلان موفقیت؛ کارت‌ها در کتابخانه با نشان وضعیت دیده می‌شوند و هر کتاب فقط یکی از این دو وضعیت را دارد.
17. **یادداشت خصوصی روی کتاب**:
    `مشخصات کتاب` -> پنل «یادداشت خصوصی» -> نوشتن یادداشت (حداکثر ۱۰۰۰ نویسه) -> `ذخیرهٔ یادداشت` -> اعلان موفقیت (با یادداشت خالی، یادداشت قبلی پاک می‌شود).
18. **دانلود کتاب (نسخهٔ فارسی)**:
    `مشخصات کتاب` -> کلیک روی `دانلود کتاب` -> دانلود فایل EPUB ترجمه‌شده به فارسی (کتاب‌های ترجمه‌نشده دکمهٔ دانلود ندارند).
19. **درخواست ترجمهٔ کتاب**:
    `لیست کتاب‌ها` -> `مشخصات کتاب` (کتابی که هنوز ترجمه نشده) -> کلیک روی `درخواست ترجمه` -> در صورت ناشناس بودن، ابتدا هدایت به ورود و پس از ورود بازگشت -> ثبت درخواست + اعلان موفقیت (دکمه به «درخواست ترجمه ثبت شد» تغییر می‌کند؛ درخواست‌ها اولویت ترجمهٔ ادمین را نشان می‌دهند).
20. **رأی به کیفیت ترجمه**:
    `مشخصات کتاب` (کتاب ترجمه‌شده) -> انتخاب امتیاز ۱ تا ۵ ستاره -> ثبت رأی + اعلان موفقیت؛ میانگین امتیاز و تعداد آرا برای همهٔ بازدیدکنندگان نمایش داده می‌شود (ناشناس‌ها ابتدا وارد می‌شوند و رأی قبلی کاربر قابل تغییر است).
21. **تغییر رمز عبور**:
    منوی کاربر -> `تغییر رمز` -> رمز فعلی + رمز جدید -> موفق -> **خروج اجباری و بازگشت به صفحهٔ ورود** (جلسات همهٔ دستگاه‌ها باطل می‌شود).
22. **خروج از سیستم**:
    کلیک روی نام کاربر در هدر -> `خروج` -> بازگشت به صفحهٔ اول با حالت ناشناس + اعلان «با موفقیت خارج شدید».

#### ج) مسیرهای مالک سیستم (System Owner / Admin)
23. **ورود ادمین**:
    `صفحهٔ ورود` -> ورود با حساب ادمین -> مشاهدهٔ نوار مدیریت (کتاب‌ها + کاربران) زیر هدر.
24. **افزودن کتاب جدید**:
    `مدیریت کتاب‌ها` (`/admin`) -> `افزودن کتاب جدید` -> انتخاب کتاب از لیست پرفروش‌های نیویورک تایمز (یا ثبت دستی) -> پر کردن فرم (عنوان، نویسنده، دسته‌بندی، توضیحات، تصویر جلد، فایل EPUB نسخهٔ اصلی) -> ذخیره -> بازگشت به لیست مدیریت + اعلان موفقیت (کتاب در لیست عمومی هم دیده می‌شود).
25. **ویرایش کتاب**:
    `مدیریت کتاب‌ها` -> کلیک روی `ویرایش` -> تغییر اطلاعات (دسته‌بندی، جلد یا فایل جدید اختیاری) -> ذخیره.
26. **حذف کتاب**:
    `مدیریت کتاب‌ها` -> کلیک روی `حذف` -> تأیید در دیالوگ -> حذف کامل کتاب (فایل‌های آپلودشده هم پاک می‌شوند؛ کتاب از کتابخانهٔ کاربران حذف می‌شود).
27. **فعال/غیرفعال کردن کتاب**:
    `مدیریت کتاب‌ها` -> کلید `فعال‌سازی/غیرفعال‌سازی` -> کتاب غیرفعال از لیست عمومی و کتابخانهٔ کاربران خارج می‌شود (ردیفش در مدیریت با نشان «غیرفعال» دیده می‌شود)؛ فعال‌سازی دوباره، آن را برمی‌گرداند.
28. **بررسی و بروزرسانی گروهی وضعیت نیویورک تایمز**:
    `مدیریت کتاب‌ها` -> بخش «وضعیت نیویورک تایمز» -> مشاهدهٔ وضعیت فعلی همهٔ کتاب‌ها (در لیست / خارج از لیست، مدت حضور، رتبه) -> انتخاب گروهی کتاب‌ها -> `بروزرسانی یکجا` -> سیستم با سرویس جستجوی NYT وضعیت‌ها را بررسی و به‌روزرسانی می‌کند -> اعلان موفقیت.
29. **جستجوی دستی کتاب در لیست پرفروش‌های نیویورک تایمز**:
    `مدیریت کتاب‌ها` (فرم افزودن/ویرایش) -> کلیک روی `جستجو در لیست پرفروش‌های نیویورک تایمز` -> وارد کردن نام کتاب -> نمایش نتیجهٔ تطبیق (رتبه، هفته‌های حضور، حضور فعلی) -> تایید و ذخیره.
30. **بررسی درخواست‌های ترجمهٔ کاربران**:
    `مدیریت کتاب‌ها` -> بخش «درخواست‌های ترجمه» -> مشاهدهٔ کتاب‌های درخواستی همراه با تعداد درخواست‌ها -> اولویت‌بندی کتاب‌ها برای ترجمه (که به‌صورت مستقل و خارج از برنامه انجام می‌شود).
31. **افزودن نسخهٔ ترجمه‌شده به برنامه**:
    `مدیریت کتاب‌ها` -> پس از دریافت فایل ترجمه‌شده از فرآیند ترجمهٔ خارجی -> بارگذاری نسخهٔ فارسی در فرم ویرایش/افزودن کتاب -> ذخیره و انتشار -> کتاب با وضعیت «ترجمه‌شده» در لیست عمومی و صفحهٔ مشخصات در دسترس قرار می‌گیرد.
32. **مدیریت کاربران**:
    `مدیریت کاربران` (`/admin/users`) -> مشاهدهٔ لیست کاربران (نام، ایمیل، تاریخ عضویت شمسی، نقش) -> `مسدود/فعال` کردن حساب، تغییر نقش (کاربر/ادمین) یا `حذف` کاربر (با تأیید؛ حساب خود ادمین قابل تغییر نیست).
33. **تغییر/بازنشانی رمز عبور کاربر توسط ادمین**:
    `مدیریت کاربران` -> کلیک روی `تغییر رمز` برای یک کاربر -> وارد کردن رمز جدید -> تأیید -> کاربر از همهٔ دستگاه‌ها خارج می‌شود.
